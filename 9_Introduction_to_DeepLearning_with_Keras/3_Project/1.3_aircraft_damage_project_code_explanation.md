# Step 3 — ImageDataGenerator

The ImageDataGenerator automatically:
- Loads images
- Resizes images
- Normalizes pixel values
- Creates batches

Example:

```python
ImageDataGenerator(rescale=1./255)
```

Why normalize?

Original image pixels range:
0 → 255

After normalization:
0 → 1

This improves neural network training stability.

```python
valid_generator = valid_datagen.flow_from_directory(
```

### batch_size=batch_size
Loads images in small batches instead of all at once.

### target_size=(img_rows, img_cols)
Resizes all images to same dimensions.

### shuffle=False
Keeps image order fixed for evaluation.

# Step 4 — Loading Pretrained VGG16 Model

## What is VGG16?

VGG16 is a pretrained Convolutional Neural Network trained on ImageNet.

It already learned:
- edges
- shapes
- textures
- objects

Instead of training from scratch, we use transfer learning.

---

# Task 3 — Load VGG16

```python
base_model = VGG16(
    weights='imagenet',
    include_top=False,
    input_shape=(img_rows, img_cols, 3)
)
```

## Explanation

### weights='imagenet'
Loads pretrained weights.

### include_top=False
Removes original classification layer because we build our own classifier.

### input_shape=(img_rows, img_cols, 3)
Defines RGB image input size.

3 means:
- Red
- Green
- Blue channels

---

# Step 5 — Freezing Layers

```python
for layer in base_model.layers:
    layer.trainable = False
```

## Why freeze layers?

We want:
- pretrained features to remain unchanged
- only train custom layers

This reduces:
- training time
- overfitting

---

# Step 6 — Custom Classification Layers

```python
model.add(Dense(512, activation='relu'))
model.add(Dropout(0.3))
```

## Dense Layer
Learns patterns from extracted VGG16 features.

## ReLU Activation
Removes negative values and helps nonlinear learning.

## Dropout
Randomly disables neurons during training to prevent overfitting.

---

# Final Output Layer

```python
Dense(1, activation='sigmoid')
```

## Why sigmoid?

Binary classification requires:
- output between 0 and 1

Example:
- 0.95 → crack
- 0.10 → dent

---

# Task 4 — Compile Model

Best loss function for binary classification.

# PART 2 — Image Captioning and Summarization using BLIP

# What is BLIP?

BLIP stands for:

Bootstrapping Language-Image Pretraining

It combines:
- Computer Vision
- Natural Language Processing

BLIP can:
- understand images
- generate captions
- generate summaries

---

# Step 1 — Loading BLIP Model

```python
processor = BlipProcessor.from_pretrained(...)
model = BlipForConditionalGeneration.from_pretrained(...)
```

## Processor
Prepares image input for the model.

## Model
Generates text from image understanding.

---

# Custom Keras Layer

```python
class BlipCaptionSummaryLayer(tf.keras.layers.Layer):
```

## Purpose
Wraps BLIP functionality into a reusable TensorFlow layer.

This layer:
- loads image
- preprocesses image
- generates text
- returns caption or summary

---

# tf.py_function()

```python
tf.py_function(...)
```

## Purpose
Allows normal Python code inside TensorFlow graph execution.

Used because:
- PIL image loading
- Hugging Face processing
cannot run directly as TensorFlow operations.

---

# Task 8 — Helper Function

```python
def generate_text(image_path, task):
    blip_layer = BlipCaptionSummaryLayer(processor, model)
    return blip_layer(image_path, task)
```

## Explanation

### image_path
Path of image.

### task
Can be:
- caption
- summary

### Returns
Generated text from BLIP model.

---

# Task 9 — Generate Caption

```python
caption = generate_text(
    image_path,
    tf.constant("caption")
)
```

## Purpose
Creates descriptive sentence for image.

Example:
"An aircraft with visible dent damage."

---

# Task 10 — Generate Summary

```python
summary = generate_text(

```

## Purpose
